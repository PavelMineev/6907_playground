# 🎲 Программа генерации случайных паролей

Эта программа предназначена для генерации случайных паролей заданной длины.
Пароли могут содержать буквы верхнего и нижнего регистра, цифры и специальные символы.

---

## 🚀 Возможности

✅ Генерация случайных паролей указанной длины
✅ Возможность выбора использования букв, цифр и специальных символов
✅ Простое и удобное консольное приложение

---

## 📌 Начало работы

🔹 **Требования:** Python 3.6 или выше

### 📥 Установка зависимостей
Перед запуском убедитесь, что у вас установлен `pytest`, если планируете запуск тестов:
```bash
pip install pytest
```

---

## 🧪 Запуск тестов
Тесты написаны с использованием `pytest`. Запустить их можно следующей командой:
```bash
pytest
```
